# Frontend do portal

- Todo SVG criado por `A.icone()` precisa de classe com largura/altura no CSS; sem isso ele se expande ao tamanho do contêiner (ex.: estrela dos favoritos).
- Classes CSS seguem o português (`primario`, `perigo`, `pequeno`, `visivel`), iguais às usadas no JS e no HTML; antes havia seletores em inglês que nunca casavam.
